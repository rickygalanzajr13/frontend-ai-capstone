# Project Rules

## 1. Form Validation
All forms must validate user input before submission. Required fields, email addresses, password confirmation, and field-specific constraints must be enforced, with clear inline error messages displayed to the user.

## 2. Accessibility
Every form control must use semantic HTML with associated `<label>` elements, keyboard-accessible interactions, visible focus indicators, and accessible validation feedback following WCAG guidelines.

## 3. Component Reusability
Reusable UI elements such as input fields, buttons, and form controls should be implemented as reusable React components to reduce duplicated code and improve maintainability.

## 4. Responsive Design
All new pages and components must follow a mobile-first responsive design approach and display correctly across mobile, tablet, and desktop screen sizes.

## 5. Verification Before Completion
Before considering a feature complete, verify that validation rules, loading states, success messages, responsiveness, and accessibility requirements work as expected. AI-generated code must always be manually reviewed and tested.
